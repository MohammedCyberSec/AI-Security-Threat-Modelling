# AI-Security-Threat-Modelling

This repository documents threat modelling work for AI and large language model systems that I am currently developing, using frameworks such as MITRE ATLAS and the OWASP LLM Top 10.

## Status

This project is in progress. Threat models and reports are added only once they have genuinely been produced.

## Structure

architecture/ will document example AI system architectures being analysed. threat-models/ will contain threat models developed for those architectures. mitre-atlas/ will map threats to the MITRE ATLAS framework. owasp-llm/ will map threats to the OWASP LLM Top 10. reports/ will contain summary reports of completed work.

## Skills being developed

AI security, threat modelling, MITRE ATLAS, and the OWASP LLM Top 10.
